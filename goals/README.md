# Цели

Источник текущих целей, текущих и предпочтительных уровней, ролей `улучшаем / guardrail / мониторинг` и их статусов — [таблица «Стратегические цели продажи» в Coda](https://docs.superhuman.com/d/_d_ipjkOdQd4/_suXg5zRE#_tuWbcT7b).

Текущий уровень является живым измерением. Baseline хранится как отдельный датированный снимок и не переписывается последующими измерениями.

Иерархия достижения и граница между характеристиками, требуемыми сдвигами и задачами описаны в `LEVEL_MODEL.md`. В задачнике Coda используется прямая связь `Сдвигает характеристику` с элементами L2.

Git не дублирует каждое текущее измерение. Он хранит правила выбора характеристик в `governance/CHARACTERISTIC_SELECTION_RULES.md` и версионируемую целевую конфигурацию в `governance/SALE_CONFIG_v0.1.md`.
