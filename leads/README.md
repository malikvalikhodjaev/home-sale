# Потенциальные покупатели

Git хранит схему процесса, но не реальные ФИО, телефоны, точные адреса или документы покупателей.

Минимальная запись в закрытой рабочей системе:

- дата и источник;
- задача покупки;
- диапазон бюджета и способ финансирования;
- срок решения;
- принятие общего двора, лестниц и формата объекта;
- ожидания по парковке;
- этап: обращение, квалификация, показ, предложение, отказ;
- главное возражение;
- следующий шаг, ответственный и дата;
- сумма предложения и чистая сумма после относимых расходов.

В старой Excel-книге использовалось правило выдачи точного адреса после квалификации: итог не ниже 7, подтверждённая совместимость с форматом и согласованный просмотр. Это историческое правило и требует отдельного принятия перед повторным использованием.
