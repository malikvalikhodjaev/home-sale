# Аналоги

Каждое исследование сохраняется отдельным датированным файлом, например `2026-08-20-olx-yakkasaray.md`.

Минимальный состав:

- дата и источник;
- критерии включения и исключения;
- таблица сопоставимых объектов;
- корректировки и ограничения сравнения;
- диапазон наблюдаемых цен;
- вывод о конкурентоспособности текущего объявления;
- решение, которое эти данные поддерживают или не поддерживают.

Удалённое объявление не удаляется из исследования: рядом отмечается дата последней доступности.
