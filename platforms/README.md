# Площадки

Площадка — отдельный конфигурационный объект: роль канала, формат, версия текста, цена, набор медиа, ссылка, дата проверки и измеряемые результаты.

Существенные различия между площадками управляются через `PUBLICATION_CONSISTENCY_CONTROL.md`.

| Площадка | Роль | Последнее известное состояние |
| --- | --- | --- |
| OLX | Основная поисковая поверхность | Снимок публикации от 15.08.2026 сохранён в `descriptions/advertising/published/2026-08-15-olx-current.md`; конкурентоспособность не подтверждена |
| Uybor | Специализированная недвижимость | Текущий статус публикации нужно проверить |
| BirBir | Дополнительный классифайд | Текущий статус публикации нужно проверить |
| Facebook | Дополнительное распространение | Канал и активные публикации нужно проверить |
| Telegram | Тематические каналы и прямое распространение | Нужен список конкретных каналов и правила версии |

Оперативные действия и статусы ведутся в [Coda](https://docs.superhuman.com/d/_d_ipjkOdQd4/_suHf3dR6#_tuB0w-bR/r1&columnId=c-iZQkDdsWup). В Git не хранятся логины, cookie, токены, телефоны кабинетов или платёжные данные.
