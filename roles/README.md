# Роли

Роль — конфигурационная единица взаимодействия: ожидаемый интерес, полномочия, ответственность и результат. Роль не равна конкретному человеку.

Один участник может исполнять несколько ролей. Смена исполнителя не создаёт новую версию роли; изменение полномочий, ответственности или интересующих характеристик — создаёт.

Реестр находится в `registry.md`. Персональные контакты исполнителей хранятся вне Git.

## Группы ролей

Иногда решение принимает не одна роль, а группа: например, покупающее домохозяйство. Это не Q-Bundle и не одна большая роль. Для такого случая используется отдельная единица принятия решения, описанная в `decision-units.md`.
