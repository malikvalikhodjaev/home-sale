# Продажа дома

[![Repository quality](https://github.com/malikvalikhodjaev/home-sale/actions/workflows/repository-quality.yml/badge.svg)](https://github.com/malikvalikhodjaev/home-sale/actions/workflows/repository-quality.yml)

Чистый рабочий репозиторий проекта продажи дома в Ташкенте.

## Текущая цель

Безопасно завершить продажу не позднее 30.08.2026 по цене не ниже 110 000 USD.

Продажа считается завершённой после получения согласованной суммы, регистрации перехода права, передачи объекта и закрытия критических обязательств.

## Где что находится

- `context/current.md` — краткий актуальный контекст.
- `goals/` — вход в цели Coda и связь с версионируемой конфигурацией.
- `work/` — вход в доску работ Coda и правила доказательства результата.
- `property/` — проверяемые факты о том, что именно продаётся.
- `portraits/` — гипотезы о совместимых типах покупателей.
- `descriptions/product-offer/` — состав и ценовая конфигурация предложения.
- `descriptions/legal/` — юридические ограничения и допустимые раскрытия.
- `descriptions/advertising/` — канонические, опубликованные и архивные рекламные тексты.
- `platforms/` — конфигурация каналов размещения без учётных данных.
- `leads/` — схема квалификации потенциальных покупателей без персональных данных.
- `deals/` — конфигурация безопасного движения от предложения до передачи.
- `market/` — аналоги и оценка конкурентоспособности.
- `operations/status.md` — локальный срез состояния работ; оперативный задачник ведётся в Coda.
- `operations/open-decisions.md` — решения, которые ещё нужно принять.
- `governance/CHARACTERISTIC_SELECTION_RULES.md` — обязательное правило выбора активных характеристик, индикаторов и guardrail.
- `governance/SALE_CONFIG_v0.1.md` — версионируемый профиль результата, трёх характеристик и gate безопасности.
- `media/` — правила и индекс фотографий; оригиналы сюда не копируются.
- `sources/LOCAL_SOURCES.md` — указатель на сырые локальные материалы.
- `STRUCTURE.md` — карта источников истины, правила именования и версионирования.

## Рабочие системы

- [Цели в Coda](https://docs.superhuman.com/d/_d_ipjkOdQd4/_suXg5zRE#_tuWbcT7b)
- [Работы и задачи в Coda](https://docs.superhuman.com/d/_d_ipjkOdQd4/_suHf3dR6#_tuB0w-bR/r1&columnId=c-iZQkDdsWup)

Coda является источником текущего состояния задач. Git хранит версии документов, объявлений и решений. Закрытый чекбокс без ссылки на результат не считается доказательством выполненной работы.

Для каждой области используется конфигурация `3 + 1`: ровно три улучшаемых элемента качества и один guardrail. Элемент имеет форму одной характеристики или одного Q-Bundle. Остальные показатели относятся к мониторингу либо не включаются.

## Правила безопасности

- Репозиторий предназначен только для приватного размещения.
- Кадастровые PDF, домовые книги, удостоверения, фотографии документов и оригинальные фотографии дома не добавляются в Git.
- Исходные файлы не перезаписываются и не конвертируются на месте.
- Для публикации создаются отдельные производные WebP-копии после проверки приватности.
- Перед публикацией новой группы файлов необходимо пройти `GITHUB_PUSH_CHECKLIST.md`.

## Автоматическая проверка

GitHub Actions запускает `.github/workflows/repository-quality.yml` при каждом push и pull request. Проверка не допускает чувствительные типы файлов и приватные каталоги, проверяет UTF-8, наличие обязательных документов и канонической целевой конфигурации.
