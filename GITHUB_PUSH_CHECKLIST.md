# Проверка перед первым push в GitHub

GitHub-репозиторий должен быть приватным.

Перед подключением remote проверить:

- [ ] В Git нет кадастровых PDF, домовой книги и фотографий документов.
- [ ] В Git нет удостоверений, телефонов, подписей, банковских реквизитов и ключей доступа.
- [ ] В Git нет оригинальной фотосерии дома.
- [ ] В текстах нет точных кадастровых идентификаторов и других данных, которые не нужны для совместной работы.
- [ ] Архивные объявления явно помечены как неактуальные.
- [ ] Текущая минимальная цена и срок не смешаны со старыми гипотезами.
- [ ] `git status` содержит только ожидаемые текстовые файлы.
- [ ] Выполнен просмотр полной разницы первого commit.
- [ ] На GitHub создан именно private repository.
- [ ] Решено, нужны ли вообще отобранные WebP в Git; по умолчанию они остаются локальными.

Remote и push настраиваются только после прохождения этого списка.
