# Сделка

Этот объект описывает движение одного выбранного предложения до безопасного завершения. Персональные данные сторон, платёжные реквизиты и сканы документов в Git не помещаются.

Минимальные состояния:

1. предложение получено;
2. условия и чистый финансовый результат сопоставлены;
3. покупатель и полномочия сторон проверены;
4. юридический маршрут и состав объекта согласованы;
5. способ расчёта принят;
6. обязательства подписаны;
7. полная оплата подтверждена;
8. переход права зарегистрирован;
9. объект и имущество переданы;
10. критические обязательства закрыты.

Обязательный gate безопасности определяется в `governance/SALE_CONFIG_v0.1.md` и `descriptions/legal/status.md`. Быстрый срок или высокая цена не компенсируют незакрытый gate.

Исполнимая последовательность gate для конкретного предложения находится в `SAFETY_GATE.md`.

Юрисдикционная квалификация маршрута: `localizations/uzbekistan/legal/sale-qualification-v0.1.md`.
