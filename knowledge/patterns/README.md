# Паттерны

Паттерн описывает повторяющуюся проблему, действующие силы, класс решения, ожидаемые доказательства и границы переноса. Он не считается автоматически выбранным методом.

- `price-time-liquidity.md` — защищённый компромисс цены и срока;
- `information-trust.md` — снижение информационной неопределённости;
- `single-variable-market-test.md` — диагностируемый цикл продвижения;
- `qualified-showing.md` — квалификация до затратного показа;
- `agent-alignment.md` — согласование роли посредника;
- `safe-closing.md` — завершение сделки через обязательный gate.
