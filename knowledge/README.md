# База знаний о продаже вторичной недвижимости

Версия среза: 15.08.2026.

Цель каталога — помочь понять предметную область, а не заменить оценщика, кадастрового специалиста, юриста или нотариуса.

## Как устроено знание

`источник → наблюдение → проблема → паттерн решения → выбранный метод → evidence проекта`

- `learning-path.md` — последовательность изучения;
- `problem-map.md` — карта проблем и классов решений;
- `beginner-mistakes.md` — ошибки новичка и способы раннего обнаружения;
- `patterns/` — переносимые паттерны с силами, компромиссами и ограничениями;
- `sources.md` — аннотированные источники и границы переноса.

## Уровни доверия

1. **Локальное обязательное правило** — актуальный официальный источник Узбекистана и квалификация специалиста по объекту.
2. **Локальное наблюдение** — данные рынка Узбекистана или собственная телеметрия продажи.
3. **Переносимое исследование** — эмпирическая работа из другого рынка; объясняет механизм, но не задаёт местное число.
4. **Практическая гипотеза** — разумный паттерн без достаточного локального подтверждения.
5. **Исторический материал проекта** — старый DPF, таблица или текст; источник идей, а не текущая истина.

## Граница с методами

Паттерн отвечает: «какой класс решения обычно работает и почему». Метод отвечает: «что именно мы делаем сейчас, в какой последовательности и с каким evidence». Принятые процедуры хранятся в `methods/`.
