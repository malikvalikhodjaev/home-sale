# Работы и пакеты

Источник текущих задач, сроков, приоритетов и состояния выполнения — [доска «Работы и задачи» в Coda](https://docs.superhuman.com/d/_d_ipjkOdQd4/_suHf3dR6#_tuB0w-bR/r1&columnId=c-iZQkDdsWup).

Git не дублирует оперативную доску. Результат работы считается подтверждённым, когда задача содержит ссылку на файл, commit, публикацию, документ специалиста или другое проверяемое доказательство. Локальный исторический срез находится в `operations/status.md`.
