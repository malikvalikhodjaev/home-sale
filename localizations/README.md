# Локализации

Локализация связывает переносимый паттерн или метод с конкретной юрисдикцией, языком, площадкой либо институциональным контуром.

Для права используется последовательность:

1. FPF задаёт общие понятия и структуру качества.
2. Предметный DPF описывает переносимый паттерн продажи недвижимости.
3. `localizations/uzbekistan/` квалифицирует паттерн по действующим официальным источникам Узбекистана.
4. `descriptions/legal/` фиксирует доказательства и решение по конкретному дому.

Локализация всегда имеет дату проверки, официальные источники, границу применимости и условия обязательного пересмотра.
