# Описания

Здесь разделены три разных представления одной продажи:

- `product-offer/` — что именно предлагается покупателю, с каким составом, ценой и условиями;
- `legal/` — что подтверждено, что требует раскрытия и какие утверждения пока запрещены;
- `advertising/` — как принятый оффер выражен в тексте конкретной публикации.

Направление зависимости: факты об объекте → юридическое описание → продукт-оффер → рекламный текст. Рекламный текст не может становиться источником нового факта.
