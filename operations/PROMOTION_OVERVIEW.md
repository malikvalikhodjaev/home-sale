# Операционный обзор продвижения

Статус: схема данных для Coda; фактический цикл ещё не запущен.

## Основной экран

На одном экране должны быть четыре блока:

1. текущая версия оффера, публичная цена и состояние gate;
2. активные размещения и ошибки согласованности;
3. результаты текущего окна;
4. одна рекомендация и принятое решение.

## Начальное состояние на 15.08.2026

- OLX: текущая публикация найдена, исходная цена около 130 000 USD; внутреннюю статистику кабинета ещё нужно внести.
- BirBir и Joyka: в выдаче обнаружена карточка того же объекта; нужно установить, является ли это самостоятельной публикацией, импортом или агрегированной копией.
- Telegram и Instagram: метод наблюдения подготовлен, активные размещения владельца не подтверждены.
- Новый цикл продвижения не запускается до юридического gate, подготовки дома, пересъёмки и принятия цены.

## Правило рекомендаций

Каждый обзор обязан завершаться одной рекомендацией из конечного списка:

- оставить конфигурацию;
- исправить распространение;
- изменить один элемент упаковки;
- перейти к следующей ценовой ступени;
- улучшить состояние объекта;
- запросить недостающее доказательство;
- остановить размещение из-за нарушения guardrail.

Фраза «продолжать наблюдать» допустима только вместе с датой, требуемым объёмом данных и решением, которое эти данные изменят.
