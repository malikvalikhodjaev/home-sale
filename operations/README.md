# Операции

- `status.md` — датированный локальный срез выполненных и открытых работ.
- `open-decisions.md` — вопросы, по которым требуется явное решение владельца.

Оперативные задачи, исполнители и сроки ведутся в Coda. Git не дублирует доску: сюда попадают устойчивые решения, результаты и срезы, которые нужны для истории и проверки.

После принятия решения соответствующий вопрос удаляется из `open-decisions.md`, а принятое значение вносится в предметный файл: конфигурацию, сведения об объекте, ценовую стратегию или объявление.
